# OneCre8 RPI Workflow

Use the portable skill at `skills/rpi-workflow/SKILL.md` for substantial project work.

- Small copy/documentation changes: quick depth.
- Multi-file feature or bug: standard depth.
- Authentication, authorization, uploads, messaging privacy, payment, schema, migration, storage, infrastructure, concurrency, or production deployment: deep depth.

Each substantial change should leave an RPI record, test results, reviewed diff, and clear deployment status. For live-impacting actions, approval and production verification are separate gates.

This workflow is an evidence aid, not a security certification or a guarantee of correctness.
