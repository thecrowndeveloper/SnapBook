# OneCre8 Engineering Skills Registry

This index activates the portable engineering skill packs added to the repository.

## Select applicable skills for each change
- **RPI Workflow** — Research → Plan → Implement with Quick, Standard, or Deep playbooks and evidence records.
- **Architecture & Code Quality** — modular design, maintainability, Python conventions, database integrity.
- **Application Security** — OWASP ASVS-informed verification for auth, authorization, sessions, APIs, inputs, uploads and dependencies.
- **Privacy & Data Sharing** — data inventory, purpose, minimization, recipients, retention, deletion and NDPA/NDPC review.
- **QA, UX & Accessibility** — regression testing, browser verification, responsive UI and WCAG 2.2 AA target.
- **Production Engineering** — reliability, backups and restore, monitoring, deployment, rollback and capacity.
- **AI Agent Engineering** — repository grounding, least privilege, prompt-injection resistance, tool safety and honest verification.
- **Marketplace Trust & Safety** — abuse scenarios, moderation, reports, appeals and marketplace integrity.
- **Payments Readiness** — transaction state, idempotency, webhooks, reconciliation, refunds, payouts and explicit approval before live activation.

## Required use
For every substantial change, select the relevant skills, follow RPI, write testable acceptance criteria, test, review the diff, and report evidence and limitations. Do not make compliance or production-readiness claims without a scoped assessment and evidence.

## Scope note
These packs are engineering aids, not security certifications, legal advice, autonomous production operators, or guarantees of defect-free code. Live payment activation remains disabled and requires a separate approved readiness review.
