# OneCre8 Design Preservation

## Protected visual baseline
The existing OneCre8 Media interface is the design baseline. Preserve its brand identity and visual system—including black, gold, white, and cream palette; cards; typography; spacing; navigation; layout; imagery; visual hierarchy; and overall composition.

- Do not redesign, restyle, replace colors, broadly refactor CSS, or change layouts without explicit user approval.
- Inspect the current implementation and affected page before changing UI.
- For a reported UI defect, make the smallest targeted correction using existing styles and tokens; do not introduce a new visual direction.
- UX, accessibility, and responsive improvements must retain the established visual identity unless the user expressly approves a redesign.
- Treat visual regression as an acceptance criterion. Compare before/after in a browser when browser tooling is available; state clearly when it is not.
